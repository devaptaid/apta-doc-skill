# Presentation HTML as the conversion source

The workflow is **Markdown → HTML → PPTX**. Both direct delivery and review-first use these same stages. Direct delivery runs them together; review-first stops after HTML until the user asks to continue.

```bash
# Review-first: keeps the Markdown source and creates HTML only
python scripts/build_deck.py deck.md --output output/deck.html
python scripts/validate_deck.py output/deck.html

# After review: convert that exact HTML to editable PowerPoint
python scripts/build_deck.py output/deck.html --output output/deck.pptx
python scripts/validate_deck.py output/deck.pptx --source output/deck.html

# Direct delivery: performs both stages and retains output/deck.html
python scripts/build_deck.py deck.md --output output/deck.pptx
```

HTML is a self-contained presentation: visible text and native tables in the DOM, absolutely positioned shapes, embedded PNG artwork, gradients, speaker notes, and bottom dot navigation matching the original reference. It works offline, without external image URLs or external scripts. Click a dot, use arrow keys, Page Up/Down, Home/End, Space, wheel, or swipe to navigate. The active dot becomes an orange pill. The 16:9 canvas fits the viewport; printing exposes all slides and hides navigation. Generated HTML and PPTX have clean backgrounds without the upstream graph-paper grid.

## Supported HTML edits

The converter reads visible slide elements rather than a hidden Markdown/JSON payload. Changing a text paragraph, table cell, inline font size/color, or element position/size changes the exported PPTX. The Markdown does not need to be present during HTML conversion. Notes inside `.speaker-notes` become PowerPoint speaker notes. Embedded PNG data travels with the HTML when the file is moved.

The contract is the HTML subset generated by this skill (`apta:format=positioned-slides-v1`):

- `section.slide` supplies layout identity and an opaque solid or linear-gradient background.
- `.apta-text` contains plain `<p>` elements with inline position, dimensions, font, size, weight, style, line height, alignment, and color. One visible element per slide has `data-role="title"`.
- `.apta-shape` uses positioned rectangles, ellipses, or rounded rectangles with fill/border styling.
- `.apta-image` uses embedded PNG data URLs and meaningful alt text.
- `.apta-table` contains native HTML table rows/cells; position and dimensions are inline. The Aptaworks table palette and cell typography are applied by both renderers.

Keep these classes and structural attributes when editing. Update visible headings and related content consistently. When continuing from reviewed HTML, do not rebuild it from Markdown and overwrite approved HTML edits. Synchronize Markdown deliberately if it will be used for a later revision.

This is not a general browser-page converter. Flexbox/grid layouts, external CSS stylesheets, remote/local image URLs, SVG, arbitrary JavaScript, rich inline markup, and browser-only effects are not imported. The converter never runs HTML scripts or fetches URLs. Base stylesheet/JavaScript changes affect the browser preview only; the supported presentation styling is the positioned elements' inline contract. Native Office and browser font metrics can produce small differences, so render the PPTX before visual sign-off.
